## What this is

A Jekyll-based GitHub Pages blog ("Absorb a Concept") using the `minima` theme (solarized-light skin). Content is authored as Markdown posts under `_posts/`; site config lives in `_config.yml`. Deployed via GitHub Pages (custom domain in `CNAME`).

## Commands

Run from the repo root. See [local_run_jekyll_mac.md](local_run_jekyll_mac.md) for full macOS setup details (rbenv, native extension build issues, etc.).

```bash
bundle install                       # install gems pinned in Gemfile.lock
bundle exec jekyll serve             # serve locally at http://localhost:4000
bundle exec jekyll serve --livereload
bundle exec jekyll serve --port 4001 # if 4000 is taken
bundle exec jekyll build             # build static site into _site/
```

Always use `bundle exec` (not a bare `jekyll` command) so the gem versions match `Gemfile.lock`, which mirrors what GitHub Pages runs in production.

There is no test suite, linter, or CI build step beyond the Dependabot config (`.github/dependabot.yml`, monthly github-actions updates).

## Structure

- `_posts/YYYY-MM-DD-title.md` — blog posts, one file per post, filename date prefix is required by Jekyll.
- `_config.yml` — site title/description, theme/skin, `nav_pages` (which top-level pages appear in nav).
- `about.md`, `01_technical.md`, `02_allvmware.md` — standalone pages; must be added to `nav_pages` in `_config.yml` to appear in navigation.
- `index.md` — homepage.
- `_site/` — generated build output; do not hand-edit, it's regenerated by `jekyll build`/`serve`.
- `.github/workflows/`, `.github/steps/` — leftover scaffolding from the original "GitHub Pages" Skills course template, not part of the active blog content.

## Notes

- New posts must follow Jekyll's `_posts` naming convention (`YYYY-MM-DD-title.md`) and include front matter (`title`, `layout`, etc.) consistent with existing posts in `_posts/`.
- To add a new standalone page to the nav, create the `.md` file at the repo root and list it under `nav_pages` in `_config.yml`.
