## What is FastAPI?
FastAPI is a Python web framework for building API's. Decorators (like @app.get("/<end_point>") are used to define endpoints, it uses Python type hints to automatically validate incoming data, convert types and generate interactive API documentation (at /docs) out of the box.

It is built on Starlette(for the web layer) and Pydantic(for data validation)
