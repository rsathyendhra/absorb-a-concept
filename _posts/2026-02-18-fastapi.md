## What is FastAPI?
FastAPI is a Python web framework for building API's. Decorators (like @app.get("/<end_point>") are used to define endpoints, it uses Python type hints to automatically validate incoming data, convert types and generate interactive API documentation (at /docs) out of the box.

It is built on Starlette(for the web layer) and Pydantic(for data validation)

### What is Starlette?
Starlette is a lightweight python web framework build on ASGI (Asynchronous Server Gateway Interface) which is sucessor of WSGI (Web Server Gateway Interface). FastAPI is built on top of Starlette by adding automatic data validation, serialization and API docs to it.

### What is Pydantic?
Pydantic is a python library for data validation using type hints. Let me elaborate with an illustration for better understanding.

```
from pydantic import BaseModel

class Customer(BaseModel):
    name: str
    age: int
    email: str
    pincode: int

user = User(name="Alice", age=25, email="alice@example.com")  # works
user = User(name="Alice", age="not a number", email="...")    # validation error
```


The above class takes 3 parameters as input name as string,age an integer and email as string. If the user passes an invalid  data type like for e.g age="not a number" it will throw a validation error as it is expecting an integer. However, Pydantic does "type coercion". Let us consider the user passes age="45", the expectation is to throw a validation error as the parameter datatype is "string" and expected datatype is "int" but in reality due to the intervention of "type coercion" the string is automatically converted to integer and the execution continues.

FastAPI uses Pydantic under the hood so that when a request comes in, the JSON body is automatically parsed and validated against your model before your function even runs.
